# Security policy

Please report a vulnerability privately, not in a public issue or pull request.

- **Email:** admin@imdusd.com
- **GitHub:** where a repository's Security tab offers **Report a vulnerability**, you can use that instead. It is on for
  [infer-protocol](https://github.com/imdusd/infer-protocol/security/advisories/new) and
  [imdusd-keeper](https://github.com/imdusd/imdusd-keeper/security/advisories/new).

Say which repository, contract or site is affected, what an attacker could do and how to reproduce it. Please do not
test against mainnet contracts in a way that puts other people's funds at risk; use a fork.

The deployed contracts are listed in [Contracts and addresses](https://imdusd.com/docs/reference/contracts-and-addresses/).
Known limits are in [Risks and open questions](https://imdusd.com/docs/economics/risks-and-open-questions/).
